# 📒 订阅账本 (Subscription Book)

> 🎉 **uTools 插件已正式发布！** 打开 uTools 搜索「**订阅账本**」即可一键安装使用，无需手动下载。

本地订阅支出管理工具，帮你搞清楚每个月在各类订阅服务上到底花了多少钱。

支持**官方供应商**（如 ChatGPT、Claude、Copilot）和**中转站**（如 AI 中转站、机场节点）两类订阅的统一管理和统计。

> 🖥️ **纯前端小工具**：单个 HTML 文件即可运行，无需后端服务器、无需安装依赖、无需联网。所有数据存储在本地，不上传任何信息，隐私安全可控。

---

## ⚡ 技术特点

- **纯前端实现**：原生 HTML + CSS + JavaScript，无框架、无构建步骤
- **零依赖运行**：网页版单个 `index.html` 双击即用，图表库已本地化打包
- **无需后端**：不依赖任何服务器，不发送任何网络请求
- **数据本地存储**：
  - 网页版：浏览器 OPFS 私有文件系统 + 外部 JSON 文件双备份
  - uTools 插件版：uTools 本地数据库（支持云同步）+ 外部 JSON 文件双备份
- **隐私安全**：数据永远只在你的设备上，代码开源可审计
- **跨平台**：网页版支持所有现代浏览器，插件版支持 uTools（Windows / macOS / Linux）

## ✨ 功能特性

### 📊 仪表盘总览
- 本月支出金额及环比变化
- 活跃订阅的月均预估费用
- 近 6 个月支出趋势折线图
- 即将到期的订阅提醒（提前 3 天高亮）

### 📋 订阅管理
- 支持「官方供应商」和「中转站」两类订阅
- 每个订阅可**自定义标签名称和颜色**（12 种预设色）
- 支持按月、按年、不定期充值三种计费周期
- 不定期充值类自动显示**累计充值金额**
- 定期订阅自动计算下次扣款日期

### 💰 充值记录
- 每笔充值记录关联具体订阅项目
- 记录充值日期、金额、支付方式、备注
- 按订阅项目和月份快速筛选
- 列表中显示对应订阅的彩色标签

### 📈 统计分析
- 累计总支出和充值笔数
- 月均支出（基于历史数据）
- 月度支出趋势柱状图
- 各订阅项目支出对比图

### 💾 数据安全
- **网页版**：浏览器 OPFS 私有文件系统存储 + 外部 JSON 文件双备份
- **uTools 插件版**：uTools 本地数据库存储（支持云同步）+ 外部 JSON 文件双备份
- 支持一键导出 JSON 备份，换电脑时导入即可迁移
- 纯本地运行，不连接任何服务器

## 🚀 快速开始

### 版本 1：纯网页版

1. 下载本仓库根目录的 `index.html`
2. 双击用浏览器打开（推荐 Chrome / Edge / Safari）
3. 开始添加订阅和充值记录
4. 数据自动保存在浏览器中，可连接外部 JSON 文件做可见备份

### 版本 2：uTools 插件版（推荐 ⭐）

> ✅ **本插件已正式发布到 uTools 插件市场**，推荐直接搜索安装，一键使用。

**安装方式：**

1. 打开 uTools，呼出搜索框
2. 点击右侧头像进入「**插件应用市场**」
3. 搜索「**订阅账本**」（也可搜「记账」「订阅管理」「充值记录」）
4. 点击「获取」安装
5. 安装完成后，在 uTools 搜索框输入「订阅账本」即可打开

## 📝 数据说明

### 示例数据
插件目录下的 `demo-data.json` 包含示例数据（6 个订阅 + 20 笔充值记录），可用于体验功能。

使用方式：将 `demo-data.json` 复制为 `subscription-data.json`，放在对应目录下即可自动加载。

```json

      "cycle": "monthly | yearly | custom",
      "price": 100,
      "startDate": "2026-01-01",
      "status": "active | paused | cancelled",
      "note": "备注",
      "tagName": "标签名称",
      "tagColor": "#007aff"
    }
  ],
  "payments": [
    {
      "id": "唯一ID",
      "subscriptionId": "关联的订阅ID",
      "date": "2026-08-15",
      "amount": 100,
      "method": "微信 | 支付宝 | 银行卡 | 信用卡 | 其他",
      "note": "备注"
    }
  ]
}
```
